# .github

Organisation-wide GitHub configuration for [TUNEXOS](https://www.tunexos.com).

## Contents

| Path                | Purpose                                                                           |
| ------------------- | --------------------------------------------------------------------------------- |
| `profile/README.md` | The public profile shown on [github.com/tunexos](https://github.com/tunexos).    |
| `profile/mark.svg`  | The TUNEXOS mark used in the profile. Copied from the brand assets in `tunexos.com`. |

Community health files added here (e.g. `CONTRIBUTING.md`, `SECURITY.md`,
issue templates) apply to every repository in the organisation that does not
define its own.

## Editing the profile

The profile is public, so keep it short and keep it consistent with the website:

- Take copy from the site's dictionaries (`tunexos.com/src/i18n/en.ts`) rather
  than writing new claims.
- Take company facts from `tunexos.com/src/lib/company.ts`. Don't add any that
  are still unconfirmed there.
- Write the name as **TUNEXOS** (uppercase).
- If the brand mark changes, copy `tunexos.com/src/assets/brand/mark.svg` here again.
